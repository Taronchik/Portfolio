Язык программирования

C

Программа и вывод

#include <stdio.h> подключает объявление printf. Выполнение начинается с main, а return 0; сообщает об успешном завершении. Вызов printf выводит строку; \n переводит строку, а ; завершает инструкцию.

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}

Сборка и запуск

С Clang программу можно собрать в терминале с предупреждениями компилятора, затем запустить готовый файл:

clang -std=c17 -Wall -Wextra hello.c -o hello
./hello

В некоторых средах команда запуска отличается; онлайн-компилятор обычно выполняет её кнопкой Run.

Строки и комментарии

Внутри двойных кавычек текст — строка. Экранированные последовательности \" и \\ выводят кавычку и обратный слеш; \t вставляет табуляцию. Комментарии // и /* ... */ нужны для пояснений и не выводятся программой.

Переменные и присваивание

Объявление создаёт имя с типом, инициализация задаёт первое значение. При присваивании сначала вычисляется правая часть, затем результат записывается в переменную. Копирование значения в другую переменную не создаёт связь между ними.

int score = 12;
score = score + 5;

Арифметика и дроби

+, -, *, / и % — сложение, вычитание, умножение, деление и остаток. Деление двух целых отбрасывает дробную часть. Для дробного результата используйте double и преобразуйте тип до деления, например (double)total / count.

Форматирование printf

Спецификаторы связывают места в строке с аргументами по порядку: %d для int, %c для символа, %f для дробного значения. Например, %.2f показывает два знака после точки, а %% выводит сам знак процента. Форматирует вывод, но не меняет сохранённое число.

Ввод через scanf

scanf читает значения по форматной строке. Передавайте адрес переменной, например scanf("%d", &count); для double при вводе используется %lf. Функция возвращает количество успешно прочитанных значений — его стоит проверять перед вычислениями.

Функции и формулы

sqrt и pow из <math.h> возвращают результат вычисления, но сами его не печатают. В некоторых сборках GCC математическую библиотеку подключают флагом -lm. Для именованных констант в примерах использовался #define.

Символы и системы счисления

char хранит код символа; в ASCII код 'A' равен 65. Символ цифры '7' отличается от числа 7; для цифр от '0' до '9' значение получают выражением digit - '0'. В C также разбирались двоичная система и восьмеричные/шестнадцатеричные литералы 026 и 0x16.

Типы, размер и диапазон

int, long long, unsigned, char, float, double и bool задают разные значения и правила вычислений. Размер можно посмотреть через sizeof, границы целых типов — через макросы из <limits.h>. Размеры и диапазоны зависят от платформы.

Преобразования и переполнение

Тип результата определяется операндами, а не переменной слева: приведение после вычисления не исправит уже переполненное умножение. Для больших результатов преобразуйте операнд до операции. Переполнение знакового целого в C не имеет гарантированного результата; переполнение беззнакового типа выполняется по модулю его диапазона.

Точность дробных чисел

float и double хранят конечное двоичное приближение, поэтому некоторые десятичные дроби, например 0.1, не представляются точно. Формат printf округляет отображаемый текст, но не исправляет и не меняет значение в переменной.

Условия и ветвление

if, else if и else выбирают действие по условию; один if может находиться внутри другого. switch выбирает ветку через case; break завершает её, default задаёт вариант по умолчанию.

Массивы

Массив хранит несколько значений одного типа. Элементы нумеруются с нуля, поэтому у массива scores первый элемент — scores[0]. Индекс должен оставаться в пределах массива.

Язык программирования

C++

Структура программы

#include подключает заголовочный файл. Для ввода и вывода подключается <iostream>. Выполнение начинается с функции main().

#include <iostream>
int main() {
    return 0;
}

Вывод и ввод

std::cout выводит данные, std::cin считывает их. Операторы << и >> задают направление передачи.

int age;
std::cout << "Возраст: ";
std::cin >> age;

Переменные и типы

Переменная хранит значение. Примеры базовых типов: int для целого числа, double для дробного, char для символа и bool для логического значения.

Первые вычисления

Первые задачи закрепляют ввод, вывод, переменные, сложение, вычитание, умножение и деление.

int first = 7;
int second = 3;
int sum = first + second;
std::cout << sum;

Язык программирования

Python

Переменные, типы и ввод

print() выводит значение, input() получает строку. Для преобразования используются int(), float(), str(); в конспекте есть числа и строки.

Условия и сравнения

if, elif и else выбирают действия по условию. Условия можно объединять и вкладывать. Операторы: >, <, >=, <=, ==, !=.

Циклы и коллекции

for, while, break, continue. Списки и словари, перебор пар через .items(), списки словарей и фильтрация записей по условиям.

Функции и ошибки

def создаёт функцию, параметры передают данные, return возвращает результат. print выводит, но не возвращает значение. Ошибки обрабатываются через try, except ValueError.

Файлы и JSON

open() открывает файл для чтения ("r") или записи ("w"). with open(...) закрывает файл после работы. Модуль json: json.dump() и json.load().

Модули, pip и API

import подключает модули. pip устанавливает пакеты, например requests. В конспекте есть HTTP GET-запросы, статус ответа, разбор JSON и получение данных GitHub API.

Язык разметки

HTML

Документ и элементы

Создание HTML-файла, базовая структура HTML5, заголовки, абзацы, форматирование текста и подключение отдельного CSS-файла.

Теги, ссылки и изображения

Блочные и строчные элементы, включая h, p, span, ссылки-якоря, изображения с атрибутами, списки ul и ol, включая вложенные.

Контейнеры и навигация

div группирует содержимое. В макетах курса были карточки, навигация nav со списком ссылок, боковая панель и подвал.

Практика курса

Карточка товара, сетка элементов, адаптивная навигация, выпадающее меню и Emmet-сокращения для ускорения набора HTML.

Язык стилей

CSS

Правила и каскад

CSS подключается отдельно и задаёт внешний вид HTML. Селектор выбирает элементы, свойства задают оформление. Каскад, специфичность и способы подключения стилей.

Размеры и расположение

margin, padding, рамки, выравнивание, контейнеры, позиционирование. Блочные, строчные и строчно-блочные элементы; единицы px, %, em, rem.

Flexbox, Grid и адаптивность

Flexbox и CSS Grid для сеток и навигации. Медиазапросы меняют раскладку под экран; адаптивные сетки, боковые панели и меню.

Состояния и оформление

:hover, выпадающее меню и бургер-кнопка на CSS, относительное и абсолютное позиционирование, CSS-анимация, Google Fonts, favicon и видеофон.

Bootstrap и сборка страницы

Пример на Bootstrap 5: контейнеры и сетка, навигация, карточки, боковая панель, карусель изображений и подвал. Публикация проекта через GitHub Pages.

Язык программирования для веба

JavaScript

Для чего нужен

JavaScript добавляет веб-страницам поведение: реагирует на нажатия, меняет содержимое страницы, проверяет формы и взаимодействует с браузерными API.

Переменные и функции

const создаёт имя, которое нельзя переназначить, а let — имя, которому можно присвоить другое значение. Функция содержит повторно используемый набор инструкций и может вернуть результат.

function sum(a, b) {
    return a + b;
}

const score = sum(2, 3);

Объекты и ссылки

В JavaScript нет C-подобной арифметики указателей. Объекты и массивы передаются через значения-ссылки; изменение объекта через одну такую ссылку видно и через другую. Примитивы вроде чисел и строк ведут себя иначе.

Скобки и точка с запятой

Фигурные скобки { } ограничивают блоки и тела функций. Точка с запятой часто может быть опущена благодаря автоматической вставке, но в учебном коде лучше придерживаться одного стиля и не ставить несколько инструкций на одной строке.

if (score > 0) {
    console.log("Положительное число");
}
